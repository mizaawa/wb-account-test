WB Pulse v@VERSION@ - Windows portable/user installer
1. Extract this ZIP to a writable folder. Double-click start.cmd for portable use.
2. Optional user installation (no administrator needed):
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
3. The launcher listens on 127.0.0.1:8080 by default; close its console to stop.
4. Set ADDR to change the bind address. Do not expose without HTTPS/access control.
5. Uninstall: stop WB Pulse, remove %LOCALAPPDATA%\WB-Pulse and the Start-menu shortcut.
6. Not Authenticode-signed. Verify SHA256SUMS.txt before running.
Files are parsed locally; checks relay credentials through this server to fixed official endpoints, without persistence.
